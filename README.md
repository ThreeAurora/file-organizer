## 📑 功能

| | |
|---|---|
| 🖼 **九宫格拖拽分区** | 九个目标分区，各自绑定任意文件夹；拖入即按当前规则归档，Toast 反馈结果 |

| 📅 **那年今日** | 独有的回溯归档模式：按年份翻旧文件（起始回溯 8 年），一键生成"那年今日 / 那年那月"目录，年份任意翻转 |
| 🔎 **Everything 联动** | 自动探测 Everything.exe；勾选后用 Everything 打开 / 定位归档结果，全盘秒搜 |
| 🎨 **分区个性化** | 每区独立配色（取色器）与自动深色文字 · 分区重命名 · 路径重选 |
| 🪟 **窗口体验** | 窗口位置与大小记忆 · 置顶开关 · **标题栏永不灰化**（拦截 `WM_NCACTIVATE`，拖放中界面始终"活着"）· 高 DPI 逐显示器感知 |
| ⚙️ **工程细节** | 移动 / 复制在后台线程执行，界面零冻结 · 配置存 `%APPDATA%`，随装随用 · PyInstaller 单文件 exe（UPX 压缩），下载即用 |

## 🥣 使用

### 直接下载

从 [Releases](../../releases) 下载 `文件归档器.exe`（单文件，约 11 MB），双击即用；配置自动存到 `%APPDATA%\文件归档器\`。

### 从源码运行

```bash
pip install tkinterdnd2
python 文件归档器.py
```

### 构建

```bash
pyinstaller 文件归档器.spec
```

产物为 `dist/文件归档器.exe`。

## 🗂 附带结构

底栏的「☑ 附带结构」是搬运方式的总开关，默认关闭（逻辑移植自姊妹项目「视频移动」）。

**它怎么归类**：勾上后不再按文件自身的时间归类，而是认源路径上已有的 `年\月\日期层\` 结构，原样接到分区路径后面：

```
拖入   G:\B站视频\2016\03\20160301\a.mp4
落到   分区\2016\03\2016-03-01\a.mp4
```

- 日期层两种写法都认：`20160301` / `2016-03-01`，落库统一成横杠格式
- 严格校验：月 01-12、日 01-31，日期层的年月必须和上层 `年\月` 对得上
- 拖入的东西必须位于日期层**之下**；拖日期层文件夹本身会被拒
- **结构不符整批拒绝**（Toast 说明原因），一个都不动
- 已在分区里的东西再拖进来 → 静默跳过
- 重名自动改成 `_1`、`_2`……已有 `xxx_3` 就从 `_4` 接着试，**绝不覆盖**
- 单次拖入上限 200 项
- 只对九宫格分区生效；「通用整理」区没有固定根目录，勾上它拖那里会被提示拒收

**它怎么搬**：

| 场景 | 做法 | 结果 |
|---|---|---|
| 同一块盘 | `os.rename` 只改目录项的名字 | **瞬间完成**，耗时与文件数量无关；所有时间戳原样保留 |
| 跨盘 | 复制后把创建时间写回去 | 创建时间、修改时间一个都不变 |
| 拖动文件夹 | 整棵树一起走，不拆开 | 每个文件、每个子目录的创建时间都保留 |

同盘那点值得强调：一个 3000 文件的文件夹也是**几毫秒**搬完，因为文件一个字节都没动，只是名字换了归属。

**勾选后「修改时间 / 创建时间」两个按钮会收起**——开了它就不再按文件时间归类，这两个"按哪个时间去归类"的选择器留着只会让人以为还能改。取消勾选即恢复。

与「仅复制」同开时：复制出来的副本同样保留创建时间（是复制不是搬运，源文件留着）。

## 🧠 三个值得一提的实现细节

- **标题栏永不灰化**：拖放操作期间 Windows 会把窗口判为"无响应"而灰掉标题栏。本工具通过 `SetWindowLongPtr` 子类化窗口过程，直接拦截 `WM_NCACTIVATE`，让标题栏始终按激活态绘制——拖再多文件，窗口看起来永远正常。
- **那年今日**：以文件的创建 / 修改时间为锚，把不同年份的旧文件各自归回"那年今日 / 那年那月"目录。翻几年前的照片、账单、聊天记录备份时，时间线一键倒带。
- **创建时间保真**：`os.utime` 只能改修改 / 访问时间，改不了创建时间，必须走 Win32 的 `CreateFileW` + `SetFileTime`；打开目录句柄要带 `FILE_FLAG_BACKUP_SEMANTICS`。而目录的创建时间必须等内容**全部落定之后**再补写（往目录里写东西会刷新它自己的时间戳），所以用 `os.walk(topdown=False)` 从深到浅处理。

测试见 `test_keep_time.py`：21 项断言，含"copy2 保不住创建时间"的反向对照。
