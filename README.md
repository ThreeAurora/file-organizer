## 📖 介绍

一个 Windows 桌面小工具：把常去的文件夹摆成九宫格，文件拖到格子上松手，就自动按时间归档进 `年\月\` 或 `年\月\日\` —— 截图归截图、账单归账单、照片归照片，不用再开文件夹一层层粘贴。

- 单文件 exe，下载双击即用，免安装
- 配置自动存在 `%APPDATA%\文件归档器\`；程序内点「ℹ 使用手册」有简版上手说明

## ✨ 功能

| | |
|---|---|
| 🖼 **九宫格拖放** | 九格各自绑定一个目标文件夹，拖入松手即归档，弹出结果提示；点击格子直接打开对应文件夹 |
| ⏱ **时间规则** | 「修改时间 / 创建时间」任选，自动分「年 / 月」，可开「具体到日」 |
| 📅 **那年今日** | 按年份回溯整理旧文件，拖到哪一年，就归到「那年的今天」 |
| 🗂 **附带结构** | 认源路径已有的 `年\月\日期层` 结构，原样搬到目标文件夹后面（同盘瞬间完成，跨盘不丢创建时间） |
| 📋 **仅复制** | 开启后只复制，不动原文件 |
| 🔎 **Everything 联动** | 勾选后点击格子，直接在 Everything 中搜索该文件夹 |
| 🎨 **分区个性化** | 右键格子：修改名称 / 重新选择路径 / 配置颜色 |
| 🪟 **窗口体验** | 置顶窗口、位置与大小记忆、高 DPI 适配；大批量搬运时界面不假死、标题栏不灰化 |
| ⚙ **设置窗口** | 底栏「⚙ 设置」：附带结构是否随启动默认开启、结构不符是否转按时间归类 |

## 🚀 用法

### 下载运行

从 [Releases](../../releases) 下载最新版 exe，双击即用，免安装。

### 首次使用

九宫格初始显示「请选择路径」——逐个点击格子，选择它对应的目标文件夹。想改名、换路径或换个颜色，右键格子操作。

### 日常归档

- 把文件 / 文件夹拖到格子上松手 → 按当前规则归档到「目标文件夹 \ 年 \ 月 \」，弹出结果提示
- 点击格子 → 打开对应文件夹
- 拖到「通用整理」区 → 同样归档，但落在文件自己旁边（适合不需要固定去处的临时整理）
- 重名自动改成 `_1`、`_2`……绝不覆盖已有文件；单次最多拖入 200 项

### 底栏开关

| 开关 | 作用 |
|---|---|
| 修改时间 / 创建时间 | 归档按哪个时间分层 |
| 具体到日 | 开：`2026\07\2026-07-01`；关：只到 `2026\07` |
| 仅复制 | 复制而非移动，原文件保留 |
| 附带结构 | 按源路径结构搬运（见下） |
| 那年今日 | 年份回溯模式（见下） |
| 置顶窗口 | 窗口始终在最前 |
| Everything | 点击格子改为在 Everything 中搜索该路径；首次使用点「自动查找」或「选择路径」指定 Everything.exe |

### 那年今日

勾上「☑ 那年今日」，点击任意格子进入年份九宫格（近 9 年）：

- 拖文件到某个年份 → 归档到「那年的今天」。例：7 月 1 日拖到「2018」→ `目标文件夹\2018\07\2018-07-01`
- 点击年份 → 打开那年的今天所在文件夹
- 「新建今天」/「新建本月」→ 在选中年份下创建「那年的今天」/ 本月全部日期文件夹（已存在自动跳过）
- 「◀ 往前 9 年」翻到更早的年份；「返回」退出该模式

### 附带结构

开启后不再按文件自身时间分层，而是认源路径上已有的结构：

```
拖入   G:\B站视频\2016\03\20160301\a.mp4
落到   目标文件夹\2016\03\2016-03-01\a.mp4
```

- 日期层 `20160301`、`2016-03-01` 两种写法都认，落库统一成横杠格式
- 同一块盘瞬间完成（只改归属，不动内容）；跨盘复制会把「创建时间」写回去，不会被洗成今天；拖文件夹时整棵树一起搬，时间戳全部保留
- 结构不符的默认转按时间归类；在「⚙ 设置」里关掉该选项，则整批拒绝、一个都不动
- 「通用整理」区没有固定根目录，勾着它也一样按时间归类

### 从源码运行

```bash
pip install tkinterdnd2
python 文件归档器.py
```
